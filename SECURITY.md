# Security Policy

This repo is the static CalmCampus website and its research material. It collects no user data, but we still take security and privacy reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead: go to the [Security tab](https://github.com/CalmCampus-FV/CalmWeb/security/advisories/new) and choose *Report a vulnerability*.

Include what you found, how to reproduce it, and the impact. You can expect an initial response within a week.

## Scope

In scope: the site in `docs/` (for example injected scripts, trackers, unsafe links, or anything that could collect visitor data) and the deployment setup. For the app, see the [CalmApp](https://github.com/CalmCampus-FV/CalmApp) repo; for the university demos served under `/quivr/`, `/demo/`, `/epfl/` and `/unil/`, the [CalmUni](https://github.com/CalmCampus-FV/CalmUni) repo.

Only the version on `main` (what is live at calmcampus.app) is supported.

## Crisis resources

This repository is not a crisis service. If you or someone else is in danger, contact your local emergency number.
